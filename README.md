## Materyal düzeni

Her hafta altında:

- `README.md`: haftanın konusu, öğrenme hedefleri, çalıştırma bilgileri ve ödevleri için açıklama dosyası.
- `projeler/`: her uygulama kendi klasöründe olacak şekilde kaynak kodları.
- `slaytlar/`: PowerPoint sunumları ve varsa PDF sürümleri.

Örnek yerleşim:

```text
01-hafta/
  README.md
  projeler/
    proje-adi/
  slaytlar/
    konu-adi.pptx
```

Bu örnek yalnızca dosya düzenini gösterir. Henüz birinci haftaya proje veya sunum atanmadı.
`.gitkeep` dosyaları, boş klasörlerin Git tarafından saklanmasını sağlar.
Derleme çıktıları, IDE önbellekleri ve bilgisayara özel ayarlar yüklenmez.
